# Support / 문의

Use [Issues](https://github.com/orockandgto-glitch/shorts-in-place-preview/issues) for bugs and feature requests. Korean and English are welcome. Include the extension version, browser version, page type, expected/actual behavior and reproduction steps. Mention other YouTube or ad-blocking extensions when relevant. Crop private details from screenshots; never post passwords, account information, payment details or full browsing history. For private enquiries, request a private contact route without posting the sensitive details.
